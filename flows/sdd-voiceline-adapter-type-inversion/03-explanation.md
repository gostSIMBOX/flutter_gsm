# Type Inversion: Объяснение и Схемы

## Простыми словами

### Сценарий 1: Одинаковый сигнал в оба канала (L, L)

**Что происходит:**
```
SIP → [L, L] → InversionPort → [L, -L] → Схема 4R+1C → Телефон
```

**На выходе InversionPort:**
- Левый канал: `L` (без изменений)
- Правый канал: `-L` (перевёрнутый)

**На входе телефона (дифференциальный сигнал):**
```
V_diff = L - (-L) = L + L = 2L
```

**Результат:** Телефон слышит **удвоенный сигнал левого канала**

---

### Сценарий 2: В правый канал уже шлётся перевёрнутый сигнал (L, -L)

**Что происходит:**
```
SIP → [L, -L] → InversionPort → [L, -(-L)] = [L, L] → Схема 4R+1C → Телефон
```

**На выходе InversionPort:**
- Левый канал: `L` (без изменений)
- Правый канал: `-(-L) = L` (инверсия инверсии = оригинал)

**На входе телефона (дифференциальный сигнал):**
```
V_diff = L - L = 0
```

**Результат:** Телефон слышит **тишину** (сигналы компенсируются)

## Таблица сценариев

| Входной сигнал | После InversionPort | Дифференциальный выход | Что слышит телефон |
|----------------|---------------------|------------------------|-------------------|
| [L, L] | [L, -L] | L - (-L) = **2L** | **Удвоенный L** ✓ |
| [L, -L] | [L, L] | L - L = **0** | **Тишина** |
| [L, R] | [L, -R] | L - (-R) = **L + R** | **Сумма L+R** ✓ |
| [0, 0] | [0, 0] | 0 - 0 = **0** | **Тишина** |

## Зачем это нужно?

### Проблема
Когда SIP аудио играет через динамик телефона, микрофон телефона это слышит и отправляет обратно → **эхо**.

### Решение
InversionPort создаёт дифференциальный сигнал (L - R). Телефонный эхоподавитель **ожидает** дифференциальный сигнал и правильно его обрабатывает.

### Результат
```
SIP → InversionPort → Телефон → Эхоподавитель → Чистый звук без эха
```

**Без InversionPort:**
```
SIP → Телефон → Микрофон слышит динамик → Эхо → Ужасно
```

## Ключевая формула

```
Дифференциальный сигнал = V_Tip - V_Ring1

Где:
  V_Tip     = Левый канал (L)
  V_Ring1   = Правый канал (после инверсии)

Если вход [L, L]:
  V_diff = L - (-L) = 2L  ✓ Телефон слышит удвоенный сигнал

Если вход [L, -L]:
  V_diff = L - L = 0  ✓ Сигналы компенсируются
```
