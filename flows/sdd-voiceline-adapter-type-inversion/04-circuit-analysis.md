## Упрощённая схема для анализа

```
    V_L (от Tip)
      │
     ┌┴┐
     │ │ R1 10k

      │
      ├───────────┐
      │           │
```

## Принцип работы: Метод суперпозиции

### Шаг 1: Вклад от левого канала (V_L)

Предположим V_(-R) = 0 (замкнут на землю):

```
    V_L
      │
     ┌┴┐
     │ │ R1 10k
     └┬┘
      │
      ├───────────┐
      │           │
     ┌┴┐         ┌┴┐
     │ │ R2 10k  │ │ R3 47k
     └┬┘         └┬┘
      │           │
      │          ─┴─
      │          ─┬─ C1
      │           │
      ├───────────┼─────► V_OUT1
      │           │
     ┌┴┐
     │ │ R4 10k
     └┬┘
      │
     GND
```

**Расчёт:**

1. R2 и R4 параллельно (оба на землю):
   ```
   R2||R4 = (10k × 10k) / (10k + 10k) = 5kΩ
   ```

2. R3 и C1 последовательно (на высоких частотах C1 ≈ короткое замыкание):
   ```
   Z_C1 = 1/(jωC) ≈ 0 на звуковых частотах
   R3 + Z_C1 ≈ 47kΩ
   ```

3. Делитель напряжения:
   ```
   V_OUT1 = V_L × (R2||R4) / (R1 + R2||R4)
   V_OUT1 = V_L × 5k / (10k + 5k)
   V_OUT1 = V_L × 1/3 = 0.33 × V_L
   ```

### Шаг 2: Вклад от правого канала (V_(-R))

Предположим V_L = 0 (замкнут на землю):

```
    GND
      │
     ┌┴┐
     │ │ R1 10k
     └┬┘
      │
      ├───────────┐
      │           │
     ┌┴┐         ┌┴┐
     │ │ R2 10k  │ │ R3 47k
     └┬┘         └┬┘
      │           │
      │          ─┴─
      │          ─┬─ C1
      │           │
      ├───────────┼─────► V_OUT2
      │           │
     ┌┴┐
     │ │ R4 10k
     └┬┘
      │
      │
    V_(-R)
```

**Расчёт:**

1. R1 и R4 параллельно (оба на землю через R2):
   ```
   R1||R4 = (10k × 10k) / (10k + 10k) = 5kΩ
   ```

2. Делитель напряжения:
   ```
   V_OUT2 = V_(-R) × (R1||R4) / (R2 + R1||R4)
   V_OUT2 = V_(-R) × 5k / (10k + 5k)
   V_OUT2 = V_(-R) × 1/3 = 0.33 × V_(-R)
   ```

### Шаг 3: Суммарный выход (суперпозиция)

```
V_OUT = V_OUT1 + V_OUT2
V_OUT = 0.33 × V_L + 0.33 × V_(-R)
V_OUT = 0.33 × (V_L + V_(-R))
```

**Но!** V_(-R) = -V_L (после инверсии правого канала)

```
V_OUT = 0.33 × (V_L + (-V_L))
V_OUT = 0.33 × 0 = 0
```

**СТОП!** Это неверно для нашего случая...

## Правильный анализ: Дифференциальный вход телефона

### Ключевое понимание

Телефон **не измеряет V_OUT относительно земли**. Телефон измеряет:

```
V_DIFF = V_MIC - V_GND
```

Где V_MIC создаётся через R4 от смесительной точки R1-R2-R3-C1.

### Правильная схема подключения

```
    От Android TRRS:
    
    Tip (L) ───────────────────────────────────────┐
                                                   │
                                                  ┌┴┐
                                                  │ │ R1 10k
                                                  └┬┘
                                                   │
    Ring1 (-R) ────────────────────────────────────┤
                                                   │
                                                  ┌┴┐
                                                  │ │ R2 10k
                                                  └┬┘
                                                   │
                        ┌──────────────────────────┤
                        │                         ┌┴┐
                        │                         │ │ R3 47k
                        │                         └┬┘
                        │                          │
                        │                         ─┴─ C1 47nF
                        │                          │
                        │                          ├─────────► К MIC телефона
                        │                          │
    Ring2 (GND) ────────┤                         ┌┴┐
                        │                         │ │ R4 10k
                        │                         └┬┘
                        │                          │
    Sleeve (MIC) ───────┴──────────────────────────┴─────────► К GND телефона
```

## Работа в частотной области

### Импеданс конденсатора C1

```
Z_C1 = 1 / (j × 2π × f × C1)

На разных частотах:
  f = 100 Hz:  Z_C1 = 1/(2π × 100 × 47×10^-9) ≈ 33.9 kΩ
  f = 300 Hz:  Z_C1 = 1/(2π × 300 × 47×10^-9) ≈ 11.3 kΩ
  f = 1 kHz:   Z_C1 = 1/(2π × 1000 × 47×10^-9) ≈ 3.4 kΩ
  f = 3.4 kHz: Z_C1 = 1/(2π × 3400 × 47×10^-9) ≈ 1.0 kΩ
```

### Частота среза ФВЧ

```
f_c = 1 / (2π × R_экв × C1)

Где R_экв ≈ R3 || R4 = 47k || 10k ≈ 8.2kΩ

f_c = 1 / (2π × 8200 × 47×10^-9)
f_c ≈ 413 Hz
```

**Вывод:** Частоты ниже 400 Гц ослабляются, голосовой диапазон (300 Гц - 3.4 кГц) проходит.

## Детальный анализ по сценариям

### Сценарий 1: Моно сигнал [L, L]

**На входах:**
- V_Tip = L
- V_Ring1 = -L (после InversionPort)

**Токи через R1 и R2:**
```
I_R1 = (V_Tip - V_node) / R1 = (L - V_node) / 10k
I_R2 = (V_Ring1 - V_node) / R2 = (-L - V_node) / 10k
```

**По закону токов Кирхгофа в узле:**
```
I_R1 + I_R2 = I_R3 + I_R4

(L - V_node)/10k + (-L - V_node)/10k = V_node / (R3 + Z_C1 + R4)

(L - L - 2×V_node)/10k = V_node / (47k + Z_C1 + 10k)

-2×V_node / 10k = V_node / (57k + Z_C1)

-2 / 10k = 1 / (57k + Z_C1)

Это уравнение не имеет решения кроме V_node = 0
```

**Вывод:** При идеальном балансе V_node = 0, но...

**На практике:** Небольшие различия в R1 и R2 создают остаточный сигнал.

### Сценарий 2: Стерео сигнал [L, R]

**На входах:**
- V_Tip = L
- V_Ring1 = -R (после инверсии)

**Ток через R1:**
```
I_R1 = (L - V_node) / 10k
```

**Ток через R2:**
```
I_R2 = (-R - V_node) / 10k
```

**Узел (приближённо, игнорируя C1 на средних частотах):**
```
I_R1 + I_R2 ≈ I_R4

(L - V_node)/10k + (-R - V_node)/10k = V_node / 10k

L - R - 2×V_node = V_node

L - R = 3×V_node

V_node = (L - R) / 3
```

**Выход на MIC:**
```
V_MIC ≈ V_node = (L - R) / 3
```

**Телефон получает дифференциальный сигнал:**
```
V_DIFF = V_MIC - V_GND = (L - R) / 3
```

## Роль каждого компонента

### R1 (10k) и R2 (10k) — Смесительные резисторы

**Функция:**
- Смешивают левый и правый каналы
- Создают взвешенную сумму: V_node ∝ (V_L + V_(-R))
- Ограничивают ток от выходов Android

**Почему 10k:**
- Достаточно высоко, чтобы не нагружать выход Android (типичный Z_out ≈ 100Ω)
- Достаточно низко, чтобы работать с входным импедансом телефона

### R3 (47k) и C1 (47nF) — ФВЧ + Изоляция

**Функция:**
- R3: Ограничивает ток через C1, создаёт ФВЧ с C1
- C1: Блокирует постоянную составляющую, пропускает только AC

**Частота среза:**
```
f_c = 1 / (2π × R3 × C1) ≈ 72 Hz
```

**Почему 47k/47nF:**
- f_c ≈ 72 Гц — ниже голосового диапазона (300 Гц)
- 47nF — стандартное значение, недорогое

### R4 (10k) — Смещение микрофона

**Функция:**
- Создаёт путь к земле для тока MIC
- Устанавливает рабочую точку для входного каскада телефона
- Вместе с R3 определяет коэффициент передачи

**Почему 10k:**
- Типичное значение для микрофонного смещения
- Совместимо с большинством телефонов

## Импедансный анализ

### Выходной импеданс схемы (для телефона)

```
Z_out = R4 || (R3 + Z_C1 + (R1 || R2))

На средних частотах (Z_C1 ≈ 0):
Z_out ≈ 10k || (47k + 5k)
Z_out ≈ 10k || 52k
Z_out ≈ 8.4kΩ
```

### Входной импеданс (для Android)

```
Z_in (каждый канал) = R1 + (остальная схема)
Z_in ≈ 10k + 10k = 20kΩ (минимально)
```

**Вывод:** Android легко驱动ит эту нагрузку (типичный Z_out ≈ 100Ω).

## Передаточная функция

### От L к V_MIC:

```
H_L(s) = V_MIC(s) / V_L(s) = R4 / (R1 + R4 + R3||Z_C1)

На высоких частотах (Z_C1 → 0):
H_L ≈ 10k / (10k + 10k + 47k) ≈ 0.15
```

### От R к V_MIC:

```
H_R(s) = V_MIC(s) / V_R(s) = -R4 / (R2 + R4 + R3||Z_C1)

На высоких частотах:
H_R ≈ -10k / (10k + 10k + 47k) ≈ -0.15
```

### Общая передаточная функция:

```
V_MIC = 0.15 × L - 0.15 × R
V_MIC = 0.15 × (L - R)
```

**Коэффициент передачи дифференциального сигнала: 0.15 (-16 dB)**

## Практические соображения

### 1. Допуски компонентов

При допуске резисторов ±1%:
- R1 = 10k ± 100Ω
- R2 = 10k ± 100Ω

**Дисбаланс:** До 200Ω между R1 и R2

**Влияние:** Неполная компенсация, остаточный сигнал синфазной помехи.

### 2. Нелинейности

- Выходные каскады Android имеют ограниченную мощность
- При больших уровнях возможна перегрузка
- R1/R2 защищают от перегрузки

### 3. Шумы

**Тепловой шум резисторов:**
```
V_n = √(4 × k × T × R × Δf)

Для R = 10k, T = 300K, Δf = 3400 Hz:
V_n ≈ √(4 × 1.38×10^-23 × 300 × 10000 × 3400)
V_n ≈ 750 nV (пренебрежимо мало)
```

### 4. Стабильность

- Пассивная схема, нет активных компонентов
- Нет проблем со стабильностью
- Работает в широком диапазоне температур

## Заключение

**4R+1C схема — это:**

1. **Пассивный микшер** — смешивает L и инвертированный R
2. **Дифференциальный драйвер** — создаёт (L - R) для телефона
3. **ФВЧ фильтр** — отрезает инфразвук (< 72 Гц)
4. **Защита** — резисторы ограничивают ток

**Ключевой принцип:**
```
V_MIC = 0.15 × (L - R)

Телефон получает дифференциальный сигнал →
Эхоподавитель работает корректно →
Чистый звук без эха
```
